**Stack**

`ASP.NET Core` `Entity Framework Core` `PostgreSQL` `Redis Stack` `Kafka` `Angular` `Docker` `Nginx`

### What I've implemented

* ⚙️ Designed and developed a REST API
* 🔎 Implemented exercise search using **Redis Stack**
* 🔐 Added authentication with **JWT and refresh tokens**
* 🗄 Refresh tokens are stored in Redis
* 🔁 Added `Idempotency-Key` support to prevent duplicate workout creation
* 📨 Added Kafka-based analytics processing
* 🐳 Containerized the application with Docker Compose
* 🌐 Configured Nginx and SSL
* 🚀 Built CI/CD with GitHub Actions
* 🎨 Developed the frontend with Angular
* 📊 Performed load testing with k6
